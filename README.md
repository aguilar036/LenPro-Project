# LenPro Project – Python, Base de Datos y Jenkins

Proyecto académico desarrollado para practicar la integración de una
aplicación en Python con una base de datos y herramientas relacionadas con
automatización e integración continua.

El propósito del proyecto fue experimentar con diferentes elementos utilizados
durante el desarrollo de software, combinando lógica de programación,
almacenamiento de información y configuración de herramientas de desarrollo.

## Objetivo

El proyecto busca demostrar la interacción entre una aplicación desarrollada
en Python y una base de datos, además de utilizarlo como parte de prácticas
relacionadas con Jenkins.

## Estructura del repositorio

- `app.py`: archivo principal de la aplicación.
- `sql.py`: código relacionado con las operaciones de base de datos.
- `templates/`: archivos utilizados para la interfaz de la aplicación.

## Tecnologías y conceptos utilizados

- Python
- SQL
- Bases de datos
- Jenkins
- Desarrollo de aplicaciones
- Automatización

## ¿Qué aprendí?

Durante este proyecto trabajé con la comunicación entre una aplicación y una
base de datos, así como con la organización de distintos componentes de un
proyecto de software.

También permitió acercarme al concepto de automatización dentro del ciclo de
desarrollo mediante herramientas como Jenkins.

Este tipo de prácticas complementa mis conocimientos de Python y me permite
comprender mejor cómo diferentes herramientas pueden integrarse dentro de un
proyecto de software.
